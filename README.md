# Advanced Quiz

Advanced Quiz is the weekly Thursday/Friday intra-class competition platform for Ebenezer International School.

## Product flow

- Teachers build subject question banks by class, term and week.
- Quiz Masters create one-class sessions and assemble multiple rounds.
- Students join with a competition code and their authenticated student identity.
- The live control room handles rounds, timers, buzzers, scoring and contestant monitoring.
- Results will record scores, response times, question analytics and an audit trail.

## Current milestone

The first UI foundation is in place: landing page, teacher question workspace, quiz-master session builder, live control-room prototype and student join screen.

The Supabase schema is the backend foundation. Realtime actions and secure role-aware database policies will be connected next.
